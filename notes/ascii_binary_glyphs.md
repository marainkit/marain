# ASCII Binary Glyphs (3×3 Grid Rendering)

Each character is rendered as a 3×3 grid where `█` = 1 (filled) and `░` = 0 (empty).

## Pattern Notes

- **Lowercase (01100xxx–01111xxx):** All start with `011`
- **Uppercase (01000xxx–01011xxx):** All start with `010`
- **Digits (00110xxx–00111xxx):** All start with `0011`
- Bit 5 (second bit from left) distinguishes uppercase from lowercase: `0` = uppercase, `1` = lowercase
- Each 8-bit byte renders as a 3×3 grid with 1 unused cell (layout: 3 rows × 3 columns = 9 cells, but we use 8 bits; the 9th cell is always `░`)
